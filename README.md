این برنامه بر اساس دستورالعمل تعیین دامنه قیمت سازمان برنامه و بودجه کشور به شماره ۱۴۰۳/۴۱۰۳۵۴ مورخ ۱۴۰۳/۰۸/۱۴ طراحی شده است.
این برنامه قابلیت محاسبه برآورد به‌هنگام و دامنه قیمت‌های متناسب برای پیمان‌های ریالی در قالب تمامی فهارس بهای متعارف (با انتخاب کاربر) و هر تعداد پیشنهاد قیمت را برای مناقصات یک و دو مرحله‌ای داراست.
برنامه، تبصره ۱ بند ۷-۲، تبصره ۱ بند ۸-۲، تبصره ۲ بند ۸-۳ و تبصره ۳ بند ۸-۳ را کنترل نموده و در صورت مصداق داشتن اعلام می‌کند.
